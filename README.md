# Obsidian GSync

Sitio estático de la configuración personal de [GSync para Obsidian](https://github.com/dg0988/ObsidianGSync):

- `index.html`: página de inicio de la app.
- `privacy.html`: política de privacidad.
- `callback.html`: página de retorno del inicio de sesión de Google (adaptada de GSync, licencia MIT; ver `LICENSE-GSync.txt`).
